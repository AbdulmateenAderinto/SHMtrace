- **Typography** — `docbuild.Manuscript.caption()`: bold title ending in a full stop, running into

## 3. Findings worth keeping

### 3.1 The N114 V region, and its stop codon

The author asked that N114 be named for the region it carries, and supplied two FASTA files.
IgBLAST assigns both to **IGHV1-47-36** (IGHV1/J558 family) at **100%** identity, with IGHD1-1 and
IGHJ3, junction `CARNYGSSYGLAYW`. The gene is therefore confirmed independently of this analysis.

The repository's own N114 reference matches that germline at only 99.3%: **two changes in CDR2**,
which the reads confirm, giving `W-I-Y-P-*-N-V-N-T-K` where germline reads `W-I-Y-P-G-N-G-N-T-K` —
an in-frame opal stop (TGA) plus a Gly→Val.

I first flagged this as a possible reference artifact. **The author corrected me: the stop is
deliberate.** It prevents antibody production, and its reversion is what Martin et al. (2002) read
out as hypermutation. Sequencing supersedes that readout, so the analysis measures mutation across
the whole V region rather than reversion at one codon, against the line's own reference, stop
included. STAR Methods and the Figure S8 legend both say so.

A detail nobody asked for but which may matter: SHMtrace called **no variant at either position in
any library** at 500 reads.

## 5. Traps

1. **Word edits are lost on rebuild.** See §2.4. Diff a returned `.docx` against a fresh build
   *before* rebuilding, and port edits into the Python sources.
2. **Significance asterisks need `docbuild`'s `\*` escape.** Written plainly, `*p < 0.05` is read as
   italic markup: the asterisks are swallowed *and* the parser desynchronises, so `J_{H}4` later in
   the same string renders with literal braces. Cost one debugging round.
3. **`SUPP_FIGS` is not in numeric order.** Deleting a legend by "everything between Figure SN and
   Figure SN+1" silently swallowed Figure S3, which sat between S5 and S6 in file order. Always
   locate entries by their own text.
4. **`renumber_supp.py check` cannot see a gap.** It validates citation *order*, not contiguity, so
   it reports "none needed" with S6 missing, and its own mapping is wrong there because it assumes a
   figure 6 still exists. See `HANDOVER.md` §3.0.
5. **Chained letter renames collide.** Relettering C→D, D→E… by string replacement produces
   duplicates mid-pass. Do it by line number, or with sentinels.
6. **`git stash` mid-edit is risky.** Used once to compare lint counts against a clean tree; it
   worked, but it silently restores files the harness is tracking. Prefer a separate checkout.
7. **A figure's canvas height may be computed inside a panel's loop.** Removing Figure S1's panel E
   left `bottom` unset until it was replaced with an explicit value.
